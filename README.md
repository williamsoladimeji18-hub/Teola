👗 Teola — AI Fashion & Wardrobe Platform

Teola is an AI-powered fashion and wardrobe management application designed to help users organize their digital wardrobe, discover outfit combinations, and receive personalized styling assistance.

The project explores how artificial intelligence can be integrated into a consumer-facing application to create personalized experiences.

«🚧 Project Status: Active Development»

✨ Overview

Teola combines digital wardrobe management with AI-powered styling to help users make better use of the clothes they already own.

The application is being developed as a modern web application with an emphasis on personalization, user experience and AI-assisted recommendations.

🚀 Key Features

- 👕 Digital Wardrobe — Organize and manage clothing items digitally.
- ✨ AI Styling Assistance — Use Google Gemini to provide intelligent styling support.
- 👗 Outfit Creation — Explore and create outfit combinations from wardrobe items.
- 🧠 Personalized Recommendations — Designed to provide recommendations based on a user's wardrobe and preferences.
- 📱 Responsive Interface — Designed for use across different screen sizes.
- 🔐 User & Data Management — Backend functionality powered by Supabase.
- ⚡ Modern Development Workflow — Built using a modern React/TypeScript development environment.

💻 Running the Project Locally

Prerequisites

Make sure you have:

- Node.js
- npm
- A Google Gemini API key
- A Supabase project (for features that require the backend)

1. Clone the repository

git clone https://github.com/williamsoladimeji18-hub/Teola-hub-s-Org.git

2. Install dependencies

npm install

3. Configure environment variables

Create a ".env.local" file in the project root.

Add your Gemini API key:

GEMINI_API_KEY=your_gemini_api_key

If the application requires Supabase configuration, add the project's required Supabase environment variables as defined in the source code.

Never commit your ".env.local" file or expose your API keys publicly.

4. Start the development server

npm run dev

The application will then be available through the local development URL provided by Vite.
